# FleetLuma

**FleetLuma** is a planned mobile-first, distributed infrastructure monitoring platform for small server fleets.

- **Mobile:** Flutter Android client
- **Coordinator:** FastAPI with SQLite
- **Hosts:** Linux and Windows Python monitoring agents (psutil)
- **Monitoring:** CPU, RAM, disk, agent heartbeat, HTTP service health, 24-hour history, top 10 processes

The repository is in **Sprint 0: project definition and UML modeling**. It does not yet contain a working implementation.

Development is tracked in [FleetLuma Jira](https://adambenarbia.atlassian.net/jira/software/projects/FL/boards/2/backlog). Public documentation must not include authentication tokens, credentials, or process command-line arguments.
